# ConectaTech

Projeto acadêmico desenvolvido para representar o site de uma ONG fictícia voltada à inclusão e à capacitação tecnológica.

O projeto foi criado utilizando conhecimentos básicos de HTML5 e CSS3 apresentados durante as aulas.

## Sobre o projeto

O site apresenta informações sobre a ONG, seus projetos sociais e as formas de participação. Também possui uma página de cadastro com formulário para pessoas interessadas em contribuir ou realizar trabalho voluntário.

## Tecnologias utilizadas

* HTML5
* CSS3

## Conceitos aplicados

Durante o desenvolvimento foram utilizados:

* Estrutura semântica do HTML;
* Cabeçalho, navegação, conteúdo principal e rodapé;
* Seções, artigos, listas, links e imagens;
* Formulários com campos obrigatórios;
* Validações nativas do HTML;
* Atributo `pattern` para controlar o formato dos dados;
* Classes para estilização dos elementos;
* Cores, tipografia, espaçamentos e bordas com CSS;
* Flexbox para organização do layout;
* Responsividade básica.

## Páginas do site

* `index.html`: página inicial e apresentação da ONG;
* `projetos.html`: informações sobre projetos, doações e voluntariado;
* `cadastro.html`: formulário de cadastro;
* `style.css`: arquivo responsável pela estilização das páginas.

## Aprendizado

Durante o desenvolvimento, tive algumas dificuldades principalmente na criação do formulário e na organização do layout com CSS.

Na parte do HTML, aprendi a utilizar melhor os elementos semânticos e o atributo `pattern` para criar validações nos campos do formulário.

O CSS foi a parte mais desafiadora, especialmente para organizar os elementos, aplicar espaçamentos e montar o layout. Para concluir o projeto, consultei documentações, exemplos e vídeos, o que ajudou a compreender melhor os conteúdos apresentados nas aulas.

Mesmo com as dificuldades, consegui aplicar os conhecimentos estudados e desenvolver uma estrutura funcional para o site.

## Como visualizar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.
